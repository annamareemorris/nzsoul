# Support Information — The Bannockburn App

**Central Otago · New Zealand**

---

## Getting Help

If you're experiencing any issues with The Bannockburn App, the steps below 
will resolve most problems.

**Restart the app**
Close the app fully and reopen it. This resolves most temporary display or 
loading issues.

**Check your connection**
The map, images, and trail information require an internet connection. All 
text content and bundled audio narration work offline.

**Update the app**
Make sure you're running the latest version. Go to the App Store → Updates 
and install any available update for The Bannockburn App.

**Location not showing on map**
Go to iOS Settings → Privacy & Security → Location Services → The Bannockburn 
App → and select "While Using the App". The map works without location 
permission but your position won't be shown.

**Audio narration stops when screen locks**
Background audio requires the silent/ringer switch to be off. If narration 
stops when the screen locks, check that your iPhone is not on silent mode.

**Calendar events not saving**
Go to iOS Settings → Privacy & Security → Calendars → The Bannockburn App → 
and enable access.

## About the App

The Bannockburn App is a free community guide for Bannockburn, Central Otago, 
New Zealand — covering local trails, heritage history, nature, arts, and the 
village directory. It is independently built and maintained.
